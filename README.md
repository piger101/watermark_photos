# 批量照片水印工具

一个 Python 小程序：读取照片文件夹和水印图片，给文件夹内每张照片的**左下角**加上水印。

* 默认不覆盖原图：结果保存到与原照片文件夹同级的 `<文件夹名>\_watermarked`。
* 输出文件夹可以用 `-o` 任意指定；文件夹不存在时会自动创建（支持多级目录）。
* 自动按 EXIF 方向把照片转正，再在“正常查看方向”的左下角定位。
* 常见 JPEG/PNG/WebP 照片会保留拍摄时间、相机型号等 EXIF 信息及 ICC 色彩配置。
* 水印支持透明 PNG；JPEG 水印也可以使用。
* 支持递归处理子文件夹，并保持目录结构。
* 单张照片失败不会中断整批任务。

## 环境要求

* Python 3.10 或更高版本
* Pillow

安装依赖：

```powershell
cd D:\\DeepseekHarness\\photo-watermarker
python -m pip install -r requirements.txt
```

## 最快用法

把里面的路径换成自己的即可（路径有空格或中文时，建议加英文双引号）：

```powershell
python .\\watermark\_photos.py "D:\\我的照片" "D:\\素材\\logo.png"
```

输出会出现在：

```text
D:\\我的照片\_watermarked
```

原图不会被修改。

如果想把成品放到自己指定的位置，加上 `-o`（目录不存在时会自动创建）：

```powershell
python .\\watermark\_photos.py "D:\\我的照片" "D:\\素材\\logo.png" -o "D:\\成片"
```

## 常用示例

递归处理所有子文件夹：

```powershell
python .\\watermark\_photos.py "D:\\我的照片" "D:\\素材\\logo.png" -r
```

指定输出文件夹，并调小、调淡水印：

```powershell
python .\\watermark\_photos.py "D:\\我的照片" "D:\\素材\\logo.png" `
  -o "D:\\成片" --scale 0.15 --opacity 0.8
```

`D:\\成片` 不存在也没关系，程序会先检查并自动创建它；如果创建失败，会给出错误并返回退出码 `2`。

想再次运行并保留已经处理过的照片：

```powershell
python .\\watermark\_photos.py "D:\\我的照片" "D:\\素材\\logo.png" -r --skip-existing
```

## 参数说明

|参数|默认值|作用|
|-|-|-|
|`input\_folder`|必填|照片所在的文件夹|
|`watermark`|必填|水印图片的完整路径，推荐透明背景 PNG|
|`-o, --output`|同级 `<文件夹名>\_watermarked`|自定义输出文件夹；不存在会自动创建|
|`-r, --recursive`|关闭|递归处理子文件夹，并保持原目录结构|
|`--scale`|`0.20`|水印宽度占照片宽度的比例|
|`--margin`|`0.03`|水印距左边和下边的距离，占照片短边的比例|
|`--opacity`|`1.0`|水印不透明度，范围 `(0, 1]`|
|`--quality`|`95`|JPEG/WebP 输出质量，范围 `1-100`|
|`--skip-existing`|关闭|输出文件已存在时跳过，适合中断后继续|
|`-v, --verbose`|关闭|出错时打印完整错误堆栈|
|`--version`|-|显示版本|

不传 `--scale` 和 `--margin` 时，默认效果是：水印宽度为照片宽度的 20%，左下角留出约为照片短边 3% 的空白。

## 支持的照片格式

JPG/JPEG/JFIF、PNG、WebP、BMP、TIF/TIFF。

HEIC/HEIF（部分 iPhone 照片）默认未支持，请先转换为 JPG 或 PNG。GIF 动图也不处理。

## 处理规则

1. 只处理照片文件夹本层的图片；加 `-r` 才处理子文件夹。
2. 水印会按 `--scale` 等比例缩放到照片宽度的 20% 左右；如果水印太高，会自动缩小到照片范围内。
3. 水印定位在照片**左下角**，距左边和下边各留出边距；不会被放到其他角落。
4. 输出文件夹可自定义；不存在时会自动创建（包括多级目录），已存在时直接写入。
5. 输出目录中的同名文件默认会被覆盖；原图始终不动。输出目录不能和原图目录相同。
6. 如果水印文件本身就在照片文件夹中，会自动跳过，避免把水印也当成照片处理。
7. 输出文件夹若位于照片文件夹内部，`-r` 模式下会自动忽略该输出文件夹，不会重复处理成品。
8. JPEG 是有损格式，即使质量设为 95 也会有一次重新编码；原图不会被改动。

## 退出码

* `0`：全部成功（或有文件被跳过）。
* `1`：有照片处理失败，其余照片仍会继续处理。
* `2`：参数或路径错误，例如文件夹不存在、找不到水印、没有可处理的照片。
* `130`：用户按下了 `Ctrl+C`。
